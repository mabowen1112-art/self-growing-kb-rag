 自生长知识库 · 使用说明（V2，2026-09-04）
════════════════════════════════════════════════

【这是什么】
 个人知识库的"半自生长"系统（挂在 Obsidian 知识库上）：
 1. 问答层：RAG 问答（md/pdf/word/图片 → 向量库 → AI 回答带来源）
 2. 生长层：系统自己 体检→规划→执行→起草，拿不准的问你

【日常你需要做的】（非常少）
 - 写笔记：用 Obsidian / 和 AI 对话（不用管系统）
 - 审草稿：AI 起草的新笔记放在 raw/_草稿/，
 打开看 → 满意就拖到 concepts/（或对应文件夹）→ 系统自动记录"已转正"
 不满意就删除 → 系统自动记录"已拒绝"
 - 跑生长：想跑就跑，双击「手动生长循环.bat」
 或者不管它：每天 22:00 自动跑（定时生长循环，含增量导入）

【三个启动器】（都在 E:\ai-learn\rag_kb\ 下，双击即可）

 1. 「启动知识库问答.bat」→ 问答界面（浏览器自动开 localhost:8501）
 2. 「手动导入.bat」→ 立即扫描新笔记入库（不等 22:00）
 3. 「手动生长循环.bat」→ 菜单式，打开后选（2026-09-15 更新）：
   1=只预览（安全，不改任何文件）  2=自动执行高置信任务（起草/修链接）  3=退出
   一圈 = 导入 → 体检 → 规划器 → 执行器 → 审核同步 → 总结
   （过程刷屏很长，结果只看最后那段「本轮生长总结」）

【系统自动做的事】（不用管）
 - 每天 22:00：完整生长循环（增量导入 → 体检 → 规划 → 执行 → 审核同步）
   （rag_kb_ingest 单独导入任务已停用，保留备用）
 - 体检发现问题（失效链接/孤立页/词典漏条目）→ 列成任务
 - 规划器看 待学习清单/对话记录 → 建议补什么知识 → 起草草稿
 - 你拖拽/删除草稿后 → 自动标记 approved/rejected 并写 log.md
 - 每轮生长循环后 → 更新知识库根目录《生长摘要.md》（最新在上，手机也能看）

【回答里的 [资料] 和 [补充] 是什么意思】
 [资料]：知识库里写的（可靠，来源见下方 来源）
 [补充]：AI 用自己知识补充的（明确标注，别当知识库内容）
 如果完全没搜到，AI 会说"知识库里没有相关内容"——不编造

【定时任务管理】（终端命令）
 停用: schtasks /change /tn rag_kb_ingest /disable
 schtasks /change /tn rag_kb_growth /disable
 启用: 同上把 disable 改 enable
 删除: schtasks /delete /tn 任务名 /f
 手动触发一次: schtasks /run /tn 任务名

【常见问题】

 Q: 页面显示"后端未连接"
 → 等 5 秒刷新（后端启动慢）；还不行重开 bat

 Q: 浏览器打不开 localhost:8501
 → 确认两个黑窗口开着；别用 103.xxx 外网地址，本地永远 localhost

 Q: 问的问题答"知识库里没有相关内容"
 → 库里确实没有；或换个问法试试

 Q: raw/_草稿/ 里东西越来越多
 → 那就是"待你审核"队列：拖走=通过，删除=拒绝，别留太久

 Q: 怎么手动跑一次体检/规划？
   → 双击「手动生长循环.bat」，菜单选 1 = 只预览（安全）

【想自动执行任务？】（默认不自动，安全第一）
   手动生长循环.bat 选 2 = 自动执行高置信任务（低置信不动）。命令行进阶：
 cd E:\ai-learn\rag_kb && uv run python growth_loop.py --apply
 （--apply 会让高置信任务自动改文件，改前有备份可回滚）
